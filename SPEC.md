**How the teacher wants it taught.** He asked for the conditional *types* by name (0, 1, 2, 3,
mixed 3/2, mixed 2/3), the *use cases* of each with examples, the *true meaning* (the backshift:
a past form that is not about past time = one step away from reality), and the *connectors other
than if*. So: name the types openly (school tests and Gateway use them), and explain every type
with the skill's models: the two dials (When? / Real or imagined?), One Step Back, the Reality
Receipt ("Truth: …"), IF takes the photo / WILL makes the promise, the past ticket (*have* + V3).
Never say "type 2 = 50% possible": real vs imagined is the speaker's view, not a percentage.

## 1. Gateway B2 Unit 6 grammar that MUST be covered (checked against the book, pp. 72–73, 76–77, 80–81)

- Zero: *If + present simple, … present simple* (generally or always true).
- First: *If + present simple, … will + infinitive* (possible/probable future).
- Second: *If + past simple, … would/wouldn't + infinitive* (imaginary or improbable, present or future); *If I were you*.
- Third: *If + past perfect, … would/wouldn't have + past participle* (imaginary past; regret).
- *unless* (= if … not, except if); *as long as*, *provided/providing (that)* (= if, only if); *in case* (= because maybe).
- *I wish / If only* + past simple (present wishes); + past perfect (past regrets); + *would/wouldn't* (someone's annoying habit).
- Book task shapes: choose the type; verbs in the correct form; correct the mistake; choose the connector;
  rewrite with a given word (2–5 words); complete with your own idea; one-word gap fill.
- Never copy a sentence from the book. Same grammar, new sentence.

### 3.1 World file `content/wN.json`

```json
{ "world": "w3",
  "lessons": [ { LESSON }, … ],
  "gate": { "id": "w3g", "items": [ 8 ITEMS ] } }
```

LESSON:

```json
{ "id": "w3l2", "name": "Building it: if + past, would + verb", "cefr": "B1", "ctype": "2", "gateway": "p.72",
  "formula": { "if": "If + past simple", "result": "would / could / might + verb" },
  "uses": [ { "use": "Giving advice", "ex": "If I were you, I'd tell the teacher." }, … 3–6 … ],
  "levels": {
    "B1": { "key": "one sentence", "body": ["para", "para", "para"], "examples": [ { "s": "sentence", "g": "note" }, … ] },
    "B2": { … }, "C1": { … } },
  "thai": "optional one-line Thai bridge (see 3.4)",
  "items": [ 8 ITEMS ] }
```

- `ctype` ∈ `0, 1, 2, 3, m32, m23, conn, wish, formal, mix`.
- `formula`: the pattern as two short strings (for connector/wish lessons use `if` = the connector frame, `result` = what follows).
- `uses`: 3–6 real use cases of this lesson's form, each with one natural example (≤ 16 words). These answer "when do people actually say this?" (facts, instructions, promises, warnings, negotiating, advice, dreams, polite requests, regret, relief, criticism, excuses …).

**The three levels** (rules from T.Chris's levelled-lessons standard):

- **Success test:** a student who reads ONLY one level's text can answer every item of that lesson and its gate items on that lesson's point, and rule out every distractor. Every level covers every tested point; only the English changes.
- **B1:** sentences under about 16 words, everyday words, grammar words glossed in brackets the first time ("the result (what happens)"), concrete steps. **B2:** fuller and clear. **C1:** full, precise, with the reason the form means what it means and the exceptions.
- `key`: 1 sentence. `body`: 3–5 paragraphs, each under about 85 words. `examples`: 3–5, `s` = the sentence, `g` = a short note; **every imagined example's note gives its Truth** ("Truth: I don't have a car — now"). One example may be a struck-out learner error: `"s": "<s>If it will rain, we'll stay in.</s>"` with the fix in `g`.
- The example sentences (`s`) should be the same at all three levels where possible (only `g` changes).
- Allowed tags in level text and item text: `<b> <em> <s>` only (`<s>` = a WRONG form). No other HTML, no markdown.
- **Write for the ear** (the text is read aloud by a recorded voice): no "e.g.", no arrows, no "=", no "+" in body paragraphs (write "plus" or use the formula field), no emoji, no IPA, no ALL CAPS, no tables. "V3" is allowed (it is read "V three"); prefer "the past participle (V3)" the first time.
- **Giveaway rules:** never copy or near-copy an item's stem or sentence into a lesson text; never list an item's exact wrong options; a "what it is not" contrast only for a genuine confusion.
- In "true meaning" lessons (w3l1, w4l1, w5, w7) teach the staircase explicitly: real → imagined is one step back on each verb (*am → were, have → had, will → would, can → could*); imagined past is two steps (*went → had gone, would → would have*). Past form, not past time. Same staircase as reported speech, different reason.

### 3.2 ITEM (lessons, gates, tests)

Common fields: `id` (`w3l2-1` … `w3l2-8`; gate `w3g-1` … `w3g-8`), `type`, `skill` (`meaning` or `form`), `ctype`, `cefr`,
`hint`, `why`, and optionally `lines` (context) and `truth`.

```json
{ "id": "w4l1-5", "type": "mcq", "skill": "form", "ctype": "3", "cefr": "B2",
  "lines": [ { "who": "Ploy", "text": "Why didn't you come to the badminton final on Saturday?" },
             { "who": "Nan",  "text": "I had tutoring." } ],
  "stem": "If I had been free, I ___ there, believe me.",
  "options": ["would be", "would have went", "would have been", "will be"], "answer": 2, "near": 1,
  "fb": ["No past ticket: \"would be\" is about now, but the final was on Saturday.",
         "The ticket is there, but \"have\" needs the past participle: been, not went.",
         "Yes: two steps back for an imagined past, with the \"have\" ticket.",
         "\"Will\" is for a real future. This final is over and Nan did not go."],
  "hint": "When is the result? Is there a past ticket?",
  "why": "Saturday is past and Nan was not free, so the result needs would have plus the past participle.",
  "truth": "Nan wasn't free on Saturday." }
```

Types:

- **`mcq`** — `stem` (use `___` for a gap, or a plain question), `options` (exactly 4, all different), `answer` (0–3), `near` (index of the near-miss distractor, ≠ answer), `fb` (4 lines, one per option, in option order). The app shuffles options, so never mention position or letters.
- **`spot`** — error identification. `stem` contains exactly four `[[segments]]`; exactly one is wrong. `answer` = index (0–3) of the wrong segment in reading order; `fix` = the corrected segment; `fb` = 4 lines (for the right segments: why that part is fine). Example stem: `If I [[would have]] known, I [[would have told]] you [[before]] the test [[started]].`
- **`type`** — the student types the missing words. `stem` has one `___`; optional `given` (the sentence to rewrite) and `keyword` (the word that must be used, in capitals, Gateway/Cambridge style); `accept` = every acceptable answer (full and contracted forms: `["would have gone", "would've gone", "'d have gone"]`); `model` = the answer shown afterwards (must be in `accept`). The app compares after lower-casing, trimming, straightening quotes, removing commas and a final full stop. Keep the gap short (1–6 words) and make the frame force one answer. No `options`, `fb`, `near`.

Rules (T.Chris's question standard + the skill's §5; all checked by reviewers):

1. Exactly one defensible answer. Options differ only on the tested point, same kind, similar length. Never key a disputed pair (*was/were* in speech; *may/might/could* against each other in a result; American *in case* = *if*; *if you will*).
2. **The context forces the key.** Every imagined-key item has a time cue (*yesterday, now, still, by now, tomorrow*) or a reality cue (*but I don't…, sadly, luckily*) on screen, in `lines` or the stem. Write the Truth line for it in `truth`. A bare *If I ___ (have) a car, I'd drive* is broken.
3. At least one near-miss distractor from the Thai-learner E-codes (E1 *will* after *if*; E2 present for an imagined present; E3/E4 no *have* ticket; E5 *If I have known*; E7 *would* in the *if* half; E9 *unless … not*; E10 *in case* = *if*; E11 *even if/though*; E17 *wish* + present). Ungrammatical distractors only in form items.
4. `hint` points to the decision ("When is the result?"), never to the answer, and never eliminates down to the key. `why` ≤ 35 words, literally true, plain English, no option letters.
5. `fb` names the mistake in plain words and the dial or step to check; never just "Wrong". For the key, start with "Yes".
6. The key is the longest option in at most 2 of a lesson's mcq items.
7. Never "correct" a real-past, evidence or speech-act conditional into a textbook type (skill Decision Test step 1).
8. Original sentences, British spelling, contexts a Bangkok girl of 13–17 knows (school, BTS/MRT, 7-Eleven, bubble tea, online shopping, LINE groups, concerts, badminton, cats, rain, PM2.5 haze). Every named student is a girl (Ploy, Fah, Nan, Mint, Praew, Bam, Jane, Pim, Mook, Fern); adults (teacher, coach, mum, aunt) may appear.
9. **Sensitivity (hard):** no monarchy or royal family in any form (no "If I were king/queen/prime minister"); no real people; no politics or protests; no religion jokes; no appearance comments; no romance or crushes; **no lottery, gambling or "a million pounds/baht"** (use a prize, scholarship or contest); no drugs, alcohol, self-harm, dieting or eating disorders; no violence; floods and haze without blame; exam stress as recoverable; regrets low-stakes (missed BTS, forgotten umbrella). No song lyrics, no named copyrighted characters or brands of games (say "a K-pop group", "a blocky game").

**Each lesson has exactly 8 items in this order:** items 1–3 `skill: "meaning"` (what is true? when? which sentence means…? which type is it? which use?), items 4–8 `skill: "form"`. Types per lesson: at least 4 `mcq`, exactly 1 `spot`, 1 or 2 `type` (typed items come last or second-last). Real conditionals (types 0/1, including as contrast items) are welcome in every world.
**Each gate has exactly 8 items** mixing the world's lessons (at least 2 per lesson where there are 3 lessons): 6 `mcq`, 1 `spot`, 1 `type`; 3 meaning, 5 form; no hints are shown in gates but still write `hint`.
